İş Akış Şeması

Siparişin sistem içinde izleyeceği yol.

1. PazarlamaSiparişi girer. Kutu / Lazer / Etiket ihtiyaçlarını seçer. Depo'ya gönderir.
→
2. Depo · İlk AşamaSorumlu atanır veya siparişi üzerine alır. Bekleniyor / Toplanıyor / Toplandı / Kutu'da / Lazer'de / Etiket'te. Tamamlandı → Operasyon.
→
3. OperasyonOnay Bekliyor → Onaylandı. Onaylanınca sipariş tekrar Depo'ya döner.
→
4. Depo · Son AşamaHazırlanıyor → Toplandı. Toplandı seçildiğinde otomatik olarak Sevkiyat'a gider.
→
5. SevkiyatSipariş Hazır görünür. Sevk Edildi seçildiğinde süreç tamamlanır.
