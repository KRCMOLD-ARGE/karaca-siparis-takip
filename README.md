# Karaca Sipariş Takip

Pazarlama → Depo → Operasyon → Depo → Sevkiyat iş akışını takip eden basit web uygulaması.

- Frontend: statik HTML/CSS/JavaScript
- Backend: Supabase PostgreSQL
- Geçici erişim: ortak erişim kodu
- Roller (şimdilik ekran simülasyonu): Pazarlama, Depo, Operasyon, Sevkiyat, Admin

Gerçek kullanıcı/rol yetkilendirmesi süreç oturduktan sonra Supabase Auth ile eklenecek.
